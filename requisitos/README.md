# Requisitos do projeto Upskills RH

Esta pasta guarda os requisitos funcionais, técnicos e de produto do projeto.

## Como vamos trabalhar

- Jeff envia requisitos, ajustes e decisões pelo Telegram.
- Sancho registra ou atualiza arquivos Markdown nesta pasta.
- Cada requisito deve ter objetivo, contexto, regras, critérios de aceite e status.
- Alterações relevantes entram no Git para rastreabilidade.

## Status sugeridos

- `rascunho`
- `em discussão`
- `aprovado`
- `em desenvolvimento`
- `validado`
- `cancelado`
